# MultiTrace

**把分散的证据串起来，让调查员看清每一步，再作判断。**

MultiTrace 是为 **2026 Deloitte Digital Camp** 制作的 AI 辅助调查交互原型。它用示范案例、证据图谱和调查工作台，把七个 Agent 的协作方案变成可以操作和讲解的流程。

[打开在线演示](https://yil337.github.io/multitrace-demo/) · [开发者主页](https://github.com/yil337)

**演示范围：** 当前仓库是使用示例数据和脚本化 Agent 活动的前端模拟，不运行真实大模型 Agent，也不连接企业业务系统。页面里的耗时、置信度和案件结果用于说明方案，不代表生产环境实测成绩。

## 可以体验什么

- **十二步调查流程**：从立案和证据准备，到多源分析、假设审阅与报告，逐步查看过程。
- **七种 Agent 分工**：了解总指挥、文档情报、实体图谱、统计分析、行为分析、假设验证和报告生成的设计职责。
- **可浏览的证据关系**：操作关系图，查看示例记录，沿引用理解证据之间的联系。
- **人工审核节点**：界面展示调查员何时授权启动、确认假设，以及批准移交。

这个原型关注的问题是：当多个 AI 组件共同参与调查，人怎样看清它们做了什么，并判断下一步是否可信？

## 当前实现与方案边界

| 浏览器中已实现 | 作为架构方案展示 |
| --- | --- |
| 案例视图切换与调查工作台 | Agent 调度与持久化后端状态 |
| 脚本化进度、日志与审核交互 | 实时大模型推理与企业数据连接器 |
| vis-network 交互证据图谱 | 生产环境证据摄取与完整性验证 |
| 示例报告与架构说明面板 | 部署、合规与性能保证 |

前端使用 **HTML、CSS 和 JavaScript**，图谱由 **vis-network** 渲染。交互逻辑与示例案件在 `index.html` 中，`pdf.html` 提供配套文档视图。

## 本地运行

需要 Python 3：

```bash
git clone https://github.com/yil337/multitrace-demo.git
cd multitrace-demo
python3 -m http.server 8000
```

打开 **http://localhost:8000**，进入调查工作台或示范案例。图谱库通过 CDN 加载，需要联网；运行模拟不需要 API Key。

演示界面以中文为主，英文 README 为查看项目设计和实现的读者提供概览。
